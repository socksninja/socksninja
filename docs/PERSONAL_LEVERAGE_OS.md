# Personal Leverage OS

## Mission

Build a globally mobile, economically independent, highly networked technical identity that can compound into company ownership, research access, capital and long-term strategic freedom.

This is the personal operating layer above individual projects. SABLE is one major asset inside it, not the whole system.

## Global Leverage Phase

Execution order:

`Connector → Independent Execution → Paid Pilot → Institutional Opportunity → Runway`

The nine strategic systems are:

1. Personal Global Identity OS
2. Opportunity Radar
3. Connector → Connector Network
4. Research Sponsorship
5. Cashflow Ladder
6. Acquisition Surface
7. Geographic Exit Option
8. Academic Bridge
9. Ekko Capital Allocation System

## Daily Personal Leverage Dashboard

Only seven primary numbers are reviewed every day.

| Dimension | Daily metric | What counts as evidence | Next-action rule |
|---|---|---|---|
| **Reality** | New external evidence count | real person, runtime, execution, reply, experiment, usage, payment, opportunity | Prefer actions that create fresh external evidence |
| **Network** | High-value connectors | active people who can open second-degree networks, production systems or institutions | Prioritize direct introductions and second-degree asks |
| **Money** | Stranger revenue / runway | non-family payment, recurring revenue, sponsorship, grants, cash buffer | Prioritize shortest path to paid validation |
| **Identity** | Credibility events | public evidence, cited work, strong profile, reference, technical contribution | Prefer signals that compound across future opportunities |
| **Institution** | Institutional opportunities | company, research lab, fellowship, grant, platform, accelerator or strategic-buyer contact | Pursue opportunities that can change trajectory, not vanity prestige |
| **Mobility** | Exit-option strength | legal/work pathways, geographic options, savings, international income, portable network | Increase optionality before irreversible moves |
| **Ownership** | Compounding assets | IP, equity, proprietary corpus, network position, reusable infrastructure, brand | Favor assets that survive the individual transaction |

## 1. Personal Global Identity OS

Canonical identity:

> Independent AI Builder · Agent Reliability · Agent Systems

The identity layer should connect GitHub, LinkedIn, personal site, SABLE, research artifacts, paid pilots and future institutional work.

Rule: every meaningful project must strengthen the same professional narrative instead of creating a disconnected identity.

Required assets:
- one canonical professional bio;
- one public evidence hub;
- one current project index;
- one contact path;
- one short explanation of what collaboration is useful.

## 2. Opportunity Radar

Scan continuously for:

- Agent Reliability / Evaluation / Observability
- Production Agent Infrastructure
- AI Safety / Verification
- Embodied AI / Robotics software
- BCI / HCI
- Research fellowships and grants
- Compute credits and research sponsorship
- AI startups, founder opportunities and technical roles
- Open-source maintainers and design partners

Score every opportunity on five axes:

`Reality value × Network value × Money value × Identity value × Ownership value`

Reject opportunities that only produce activity without compounding value.

Primary goal: build second-degree reach.

`Connector → Operator → Founder → Research/Platform → Capital/Strategic buyer`

Never optimize for raw contact count.

## 4. Research Sponsorship

Maintain a parallel route for resources that are awarded because a research question is valuable.

Target:

- independent research sponsorship;
- fellowships;
- research grants;
- compute credits;
- startup/research programs;
- university/lab collaborations;
- sponsored evaluations or infrastructure experiments.

Required sponsorship packet:

1. research question;
2. why current systems fail;
3. hard evidence already obtained;
4. proposed next experiment;
5. exact resource request;
6. expected public/private deliverable;
7. why the sponsor gains leverage.

## 5. Cashflow Ladder

Progression:

`$50–200 proof → $300–1,000 repeatable service → $1k–5k productized service → recurring revenue → software/product → company`

First principle: first stranger payment matters more than amount.

Current paid wedge:

**PAID PILOT — Agent Reliability Evidence Audit**

One workflow + one runtime + one reliability question.

Never claim revenue before the payment actually occurs.

## 6. Acquisition Surface

SABLE's long-term acquisition surface is not merely source code.

Compound assets:

- cross-runtime failure corpus;
- externally verified execution traces;
- reliability taxonomy;
- verification methods;
- problem-owner network;
- public evidence history;
- standards/receipt vocabulary;
- institutional relationships.

Every new SABLE action must answer:

> Does this make the reality-layer harder to reproduce than the repository itself?

If not, keep the implementation minimal.

## 7. Geographic Exit Option

Build optionality before making irreversible geographic decisions.

Track:

- portable cash buffer;
- international income;
- legal work/residence pathways;
- passport/visa knowledge;
- global professional identity;
- trusted overseas contacts;
- company/research opportunities outside the current geography.

Objective:

> No single city, family structure, employer or local market should remain a single point of failure.

## 8. Academic Bridge

Formal education is an amplifier, not the current main engine.

Bridge sequence:

`real work → public evidence → global identity → strong references → institutional opportunity → top university / research pathway`

Prepare an evidence portfolio continuously:

- hardest technical work;
- external validation;
- publications / technical notes;
- open-source contributions;
- research questions;
- references from credible operators/researchers;
- measurable real-world outcomes.

Never optimize for credentials without corresponding capability and evidence.

## 9. Ekko Capital Allocation System

Every hour, dollar and relationship is capital.

Score actions by:

`Direct leverage + compounding + reversibility + ownership + external reality`

Priority classes:

### A — Execute now
Directly increases money, network, identity, institution, mobility or ownership.

### B — Strategic support
Strengthens A-class actions and removes a real bottleneck.

### C — Technical work
Allowed only when tied to an external bottleneck, proof requirement or near-term asset.

### D — Self-amusement
No strategic justification. Cut.

Anti-drift rule:

> No External Reality → no additional internal complexity.

High score + fast signal + high reversibility = priority.

## Hard Constraints

1. Do not return to runtime expansion merely because it feels productive.
2. Do not count self-generated artifacts as external validation.
3. Do not count outreach sent as a Connector success; count replies, introductions, experiments, usage or other concrete signals.
4. Do not count a published price sheet as revenue; count payment.
5. Do not count an application as an institutional opportunity; count substantive contact, interview, sponsorship, collaboration or offer.
6. Do not trade geographic optionality for prestige without a clear expected-value advantage.
7. Prefer ownership and compounding assets over one-off labor when expected value is comparable.

## Weekly Review

Every seven days:

1. Recompute the seven Dashboard dimensions.
2. Identify the single weakest dimension.
3. Identify the strongest leverage point that can improve that dimension within seven days.
4. Stop projects that do not affect the weakest dimension or the highest-value strategic asset.
5. Update the next seven-day capital allocation.

## End State

The system succeeds when:

`SABLE evidence + connector network + cashflow + public identity + institutional access + geographic optionality + ownership`

form a self-reinforcing loop that makes the next opportunity easier to reach than the previous one.
